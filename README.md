# SOYER ONE

Native Android app built with Kotlin and Jetpack Compose.

## Design

The app follows the SOYER visual identity: deep near-black backgrounds, dark forest-green surfaces, and emerald accents. It is a standalone Android project and does not modify the SOYER EXCHANGE repository.

## Build

Open this repository in Android Studio, allow Gradle sync, then run the `app` configuration on an Android device or emulator.

- Minimum Android version: Android 8.0 (API 26)
- Language: Kotlin
- UI: Jetpack Compose

The initial version provides an informational dashboard and an editable exchange-rate calculator. It does not process payments or transfer funds.
